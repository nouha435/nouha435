## Projets phares

1. E‑recrutement — ASP.NET Core MVC, C#, EF Core, Bootstrap  
   Auth par rôle, CRUD offres/profils, pagination/filtre, export CSV.  
   Lancer: `dotnet restore && dotnet run` → http://localhost:5000

2. Actualités — Node.js/Express + Bootstrap  
   Consommation d’API, filtres par catégorie, pagination côté serveur.  
   Lancer: `npm install && npm start`

3. Géoportail Grand Casablanca — ArcGIS Maps SDK, PostGIS  
   Couches thématiques, recherche, popups d’attributs.

4. Visualisation 3D Rabat — CesiumJS  
   POIs cliquables, caméra initiale, styles.

5. Desktop — C++/Qt  
   CRUD entités, recherche multi‑critères, export PDF.

6. Manipulation hexadécimale  
   Parsing robuste, formats personnalisés, tests de base.
